# Mammo-CLIP EfficientNet Encoder

This directory contains the minimal EfficientNet implementation required
to load the Mammo-CLIP B5 image encoder used by the classical longitudinal
future-risk model.

## Source

- Project: Mammo-CLIP
- Repository: https://github.com/batmanlab/Mammo-CLIP
- Source commit: `0d68563352c06784400080e140ae3d447e779283`
- Original files:
  - `efficientnet_custom.py`
  - `efficient_net_custom_utils.py`

The two source files are currently preserved without modification.
